# AI Code Guide 機能カタログ

この文書は、AI Code Guideを初めて使う人と、保守を引き継ぐ開発者のための機能一覧です。AI Code GuideはPythonコードの理解を支援するVS Code拡張で、CodexやClaude Codeなど普段使うAIから表示を呼び出すこともできます。

## 最初の起動

この文書は拡張がインストール済みであることを前提にします。開発版を試す場合はリポジトリ直下で `./debug.sh` を実行してください。`examples` をワークスペースにした「拡張機能開発ホスト」が開きます。

1. VS CodeでPythonファイルを開く
2. 左のActivity BarにあるAI Code Guideのアイコンを押す
3. サイドバー上部のタブを、下の表から目的に合わせて選ぶ

標準・構成・既に保存された図や解説の表示には、新しいAI生成は不要です。「AI説明」「生成」「別の入力例」「質問送信」などを実行すると、設定したAPIまたはサブスクCLIを使用します。認証方式によってAPI課金またはサブスク利用枠を消費する可能性があります。

## 最初に選ぶ機能

| 知りたいこと | 使う場所 | 得られるもの |
|---|---|---|
| 今見ているファイルには何があるか | 標準 | 関数・クラスのカードと呼び出し関係 |
| ファイルを短時間で把握したい | 概要 | ファイル説明と意味ごとのグループ |
| リポジトリの構造を知りたい | 構成 | 設計資料、ディレクトリ、Pythonファイル、import関係 |
| 特定機能の処理順や依存先を知りたい | 図 | 質問に合わせた処理順・読解順・依存関係の図 |
| コード上で難所や問題点を見つけたい | 解説 | トークン下線、ブロック枠、右余白の説明 |
| 具体的な入力で値の変化を追いたい | トレース | 各行の変数値、戻り値、ループ周回 |
| 表示内容について追加質問したい | チャット | コード位置を引用した継続会話 |
| AI利用量を確認したい | 使用量 | トークン・概算コスト・研究セッション記録 |
| AIや表示方法を変えたい | 設定 | 認証、モデル、注釈、表示、研究モード |
| 操作方法を調べたい | ヘルプ | 使い方、ショートカット、フルページマニュアル |

## 10個のタブ

### 1. 標準

開いているPythonファイルのトップレベル関数とクラスをカード表示します。カードは展開・折り畳みでき、AIによる説明やブロック分解を追加できます。呼び出し矢印、カードの色分け、全展開、複数カードの範囲展開を切り替えられます。

- コード行を選ぶと対応カードを強調する
- カードや図の地点からコードへ移動する
- 右クリックの「標準カードへ移動」または `Cmd+Alt+M` で現在位置のカードへ戻る
- 粒度は概要・通常・詳細、または自然言語で指定する

### 2. 概要

ファイル全体を読む前の入口です。AIがファイルの目的を説明し、関数・クラスを意味の近いグループにまとめます。生成結果はキャッシュされます。

### 3. 構成

ワークスペース全体を対象に、次をまとめて表示します。

- `.ai-code-guide/design/` などに保存された設計情報
- ディレクトリ単位の説明
- Pythonファイルのカード
- ファイル間のimport依存

ファイルカードを押すと、そのファイルの標準表示へ移動します。設計資料がない場合は、外部AIへ設計資料の作成を依頼するプロンプトをコピーできます。

### 4. 図

「注文確定から保存まで」のような質問から、関係するコード地点を探して図にします。質問に応じて次の形式を自動選択します。

- 処理順: 実行の流れを縦フローで表示
- 読解順: 読む順番を番号付きタイムラインで表示
- 依存関係: 呼び出し先や構成要素をアウトライン表示

ノードは実在するファイル・関数・行へ照合され、押すとコードと標準カードへ移動します。質問と結果はワークスペースごとに最大30件保存されます。「HTMLで開く」で、会話の横に置ける自己完結HTMLも生成できます。

### 5. 解説

LLM自身に「説明すべき箇所」を選ばせ、行単位ではなく意味単位で表示します。

- `symbol`: 特定トークンを点線で下線表示し、行下・右余白・ホバーのいずれかに説明を出す
- `block`: 複数行を枠で囲み、右余白へサイドノートを出す
- `info` は通常の理解補助、`warning` はバグや注意点

全体生成、選択範囲だけの生成、再生成、クリアに対応します。密度、警告のみ、symbol/block別、未読・読んだ・後で・解決済み・非表示で絞り込めます。編集後はアンカー文字列から位置を取り直し、追従できない説明だけを破棄します。一括変更を検知した場合は、解説生成の提案または自動生成もできます。

### 6. トレース

関数へ具体的な入力例を与えて実行し、各行の右側に変数の実値を表示します。入力例と副作用判定はLLM、値そのものはPython実行から取得します。

- 1関数またはファイル直下の複数関数を実行
- 戻り値、変更された変数、ループ周回を表示
- `Cmd+Alt+←/→` で周回を切り替え
- 同じコードと関数の結果をキャッシュ
- 副作用ありと判定した関数は実行しない

対象はトップレベルの関数です。メソッド、外部サービスを必要とする処理、再帰の全フレーム追跡には制限があります。

### 7. チャット

コード位置や注釈を引用して追加質問できます。コード本文を複製するのではなく、ファイルと行範囲の参照を会話へ接続します。

- エディタの選択範囲を `Cmd+Alt+Q` で引用
- 注釈の「質問する」から文脈付きの会話を開始
- 会話履歴の保存・再表示
- 質問と回答のコピー
- 理解確認用の採点や会話の結論生成に使う内部処理

CodexやClaude Codeを主な対話相手にする運用では、この内蔵チャットを使わなくても構いません。

### 8. 使用量

モデル呼び出しの入力・出力トークンと概算コストを記録します。古い生ログを集約して全期間累計を維持します。研究モードではセッション単位の記録ウィジェットも表示できます。

### 9. 設定

主な設定群は次の通りです。

- 認証: Anthropic/OpenAI/Gemini APIキー、Claude/Codexサブスク
- モデル: 構造生成、チャット、インライン解説・トレースを個別指定
- 説明: 利用者の習熟度などを全プロンプトへ渡すグローバルコンテキスト
- 自動動作: ファイル表示、AI説明、インライン解説、一括編集検知
- 表示: 矢印の側、注釈密度、symbolの位置、状態ボタン、各種フィルター
- 研究: 研究モードと利用記録

APIキーはVS Code SecretStorageへ保存します。旧設定に平文で残っているキーは起動時に移行・消去します。

### 10. ヘルプ

狭いサイドバー内の操作説明と、図入りのフルページマニュアルを提供します。コマンドパレットから、ようこそガイドとフルページ版を直接開くこともできます。

## Codex / Claude Codeから使う

拡張が起動すると、ワークスペースに `.ai-code-guide/ai-code-guide.mjs`、`.ai-code-guide/ai-code-guide-mcp.mjs` と接続情報が作られます。外部AIはCLIを直接実行するか、MCPツールとして登録して、localhostだけを使って既存の理解支援画面をVS Codeに表示できます。

```bash
node .ai-code-guide/ai-code-guide.mjs status
node .ai-code-guide/ai-code-guide.mjs show standard --file src/example.py --line 10
node .ai-code-guide/ai-code-guide.mjs show overview --file src/example.py
node .ai-code-guide/ai-code-guide.mjs show project
node .ai-code-guide/ai-code-guide.mjs show diagram --question "この機能の処理順"
node .ai-code-guide/ai-code-guide.mjs show inline --file src/example.py --run
node .ai-code-guide/ai-code-guide.mjs show trace --file src/example.py --line 10 --run
```

`--run` を付けない限り、新たなLLM生成やコード実行は始まりません。図のHTML内のノードはlocalhostブリッジを通じてVS Codeへ繰り返しジャンプできます。詳細は [agent-usage.md](agent-usage.md) を参照してください。

ChatGPTデスクトップとClaude Desktopを含むMCPクライアントへの登録方法は [mcp-usage.md](mcp-usage.md) を参照してください。

## キーボード操作

Macでは `Cmd`、Windows/Linuxでは同じ位置の `Ctrl` を使います。

| 操作 | キー |
|---|---|
| 標準表示を開く | `Cmd+Alt+V` |
| インライン解説を生成 | `Cmd+Alt+E` |
| 解説またはトレースを解除 | `Cmd+Alt+C` |
| 選択範囲をチャットに引用 | `Cmd+Alt+Q` |
| 現在位置の標準カードへ移動 | `Cmd+Alt+M` |
| 現在の関数をトレース | `Cmd+Alt+T` |
| トレースの前後の周回 | `Cmd+Alt+←/→` |

## 対応範囲と安全境界

- コード構造、概要、プロジェクト構成、コード図、注釈、チャットはPython・JavaScript・TypeScriptに対応
- 実行トレースはPythonのみ対応
- LLMを使う機能にはAPIキーまたはログイン済みCLIが必要
- トレースは任意コード実行を伴うため、副作用判定、`__main__` 非実行、10秒タイムアウトで危険を抑える。ただし完全なサンドボックスではない
- localhostブリッジはランダムトークン付きで、ワークスペース外のファイルを拒否する
- AIの説明や問題指摘は判断材料であり、正しさを保証しない
- 理解目標の合意や最終的な理解到達の判定は、現時点ではAI Code Guide単体の担当外

## 用語

| 用語 | この文書での意味 |
|---|---|
| LLM | 説明や入力例を生成するClaude、GPT、GeminiなどのAIモデル |
| CLI | ターミナルから実行するコマンド。外部AI連携では `ai-code-guide.mjs` を指す |
| Webview | VS Code拡張がサイドバーや別ページに表示するHTML画面 |
| localhost bridge | 同じMac内の外部AI CLIとVS Code拡張をつなぐ、外部公開されない一時HTTP接続 |
| 自己完結HTML | 外部CDNやVS Code APIなしで、単体ファイルとして図を表示できるHTML |
| 再アンカー | コード編集後に、保存した文字列を手掛かりとして注釈位置を探し直す処理 |
| Extension Development Host | 開発中の拡張を通常のVS Code環境と分けて試すためのVS Codeウィンドウ |
| 研究モード | 評価実験用に利用量やセッションを記録する表示。通常利用ではOFFでよい |

## フローチャート / マップ

Python ファイルを開いて **⌘⌥V**（Win/Linux: **Ctrl+Alt+V**）で表示します。保存すると自動更新されます。

### タブの使い分け
- **標準** — 関数・クラスをカードで一覧。カードをクリックすると、その関数のフローチャートに入ります。
- **概要** — ファイルを意味グループでまとめた俯瞰ビュー。
- **プロジェクト** — ワークスペース全体の Python ファイルと import 依存を矢印（○ → ▶）で表示。カードをクリックで掘り下げ。

### 操作
- **AI説明** ボタンで各カード/ノードに説明文を付けます（トークンを消費・キャッシュあり）。
- ノードをクリック → 対応するコード行へジャンプ。
- コード行をクリック → 対応するノードをハイライト。
- チャット入力欄に「ざっくり」「細かく」「`hash_password` だけ」と打つと粒度を変えられます。
